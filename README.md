# 后台按键助手

一个 vibe coding 的 macOS 小工具，可将指定按键事件发送到选中的后台应用，适合向 PlayCover 中运行的应用发送键盘输入，搭配 PlayCover 的键盘映射功能实现类似连点器的效果。

## 功能

- 自动列出当前有可见窗口的应用并显示 PID；可手动刷新列表。
- 默认发送 `T` 键，也可以选择其他单个按键。按键选择会保存在本机设置中。
- 设置最短和最长按键间隔，程序会在范围内随机选择间隔。输入必须是大于 0 的数字，且最小值不能大于最大值；实际间隔不会低于 30 ms。间隔设置会保存在本机。
- 配置开始和停止快捷键，默认分别为 `⌥⌘Space` 和 `⌥⌘Esc`。
- 可选择在目标应用切换到前台时自动暂停。该开关默认开启，并会保存设置；按键发送期间不可更改。
- 检测辅助功能权限，未授权时显示提示，并提供打开系统设置的入口。

## 系统要求

- macOS 13 或更新版本
- Apple Silicon Mac
- Xcode Command Line Tools（提供 `swiftc`）

## 构建和运行

```sh
git clone https://github.com/Siriusq/BackgroundKeyPress.git
cd BackgroundKeyPress
./build_app.sh
open "后台按键助手.app"
```

构建脚本会在仓库根目录生成 `后台按键助手.app`，并为本地运行进行 ad hoc 代码签名。每次修改源码后重新运行 `./build_app.sh` 即可更新应用。

## 辅助功能授权

首次使用时，如果应用提示缺少权限：

1. 点击应用中的“打开系统设置”，或手动打开“系统设置 → 隐私与安全性 → 辅助功能”。
2. 启用“后台按键助手”。如果列表中没有该应用，点击“+”，选择刚构建的 `后台按键助手.app`。
3. 返回应用。程序会自动检查授权状态。

如果把应用移动到其他位置或重新构建后授权失效，请在辅助功能列表中移除旧条目，再添加新位置的应用。

## 使用方法

1. 在“目标程序”菜单中选择应用。
2. 按需选择发送的按键并设置间隔范围。
3. 点击“开始”或使用开始快捷键；点击“停止”或使用停止快捷键结束。
4. 开启自动暂停后，目标应用切换到前台时程序会停止发送按键。发送期间目标程序和自动暂停开关不可调整。

目标应用列表只包含有可见窗口的普通应用；隐藏、最小化或没有窗口的程序不会列出。

## 项目结构

```text
Sources/BackgroundKeyPress/
├── BackgroundPressApp.swift  # SwiftUI 应用入口
├── ContentView.swift         # 界面和窗口交互
├── Models.swift              # 应用、快捷键模型和按键名称转换
└── PressController.swift     # PID 检索、权限、快捷键和按键发送
build_app.sh                  # 构建 .app 的脚本
icon/                         # 应用图标资源
```
